# Hi, I'm Joseph (better known as Wheelbarrel00)

I'm a self-taught developer who started out annoyed at World of Warcraft's UI and decided to fix it myself. One thing led to another. Now I ship addons that people actually use, and I'm finally doing something I've always wanted to do: write the actual code.

Short version: I picked up Lua in January 2026, shipped my first addon by April, and haven't stopped since.

## What I build

Addons that make WoW a little less chaotic, published on CurseForge under Wheelbarrel00:

- **Loot Pro**: loot management, because deciding what to keep shouldn't require a spreadsheet.
- **Everything Quests** and **Everything Delves**: quest and content tracking that keeps up across patches.
- **Cooldown Master** (beta): a real-time cooldown HUD currently arm-wrestling Midnight's new combat restrictions.

Then I figured if I could write Lua, I could probably write other things too. So far, so good.
